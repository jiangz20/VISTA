# README figures

- **banner.png**: project header using the manuscript's pale-blue color palette.
- **method.png**: raster export of the manuscript's method figure (2200 px wide).
- **sensitivity.png**: raster export of the manuscript's sensitivity figure (2000 px wide).

The two paper figures preserve the original content and reported values from
[VISTA, arXiv:2609.38086](https://arxiv.org/abs/2609.38086). Figures are stored locally
so the README does not depend on temporary files or external image hosting.
